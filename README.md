# ChessFaces Minecraft Texture Pack

ChessFaces is a Minecraft texture pack that replaces the default chess pieces with custom chess pieces featuring faces. The pack includes chess pieces with brown hair and brown eyes, designed to fit the theme of chess. This texture pack is perfect for players who enjoy customizing their Minecraft experience with unique and thematic textures.

## Install

1. Download the ChessFaces texture pack from the GitHub repository.
2. Open Minecraft.
3. Click on "Options" in the main menu.
4. Navigate to the "Resource Packs" tab.
5. Click on "Open Resource Pack Folder".
6. Drag and drop the downloaded ChessFaces texture pack into the resource pack folder.
7. Go back to the "Resource Packs" tab in Minecraft.
8. Enable the ChessFaces texture pack by clicking on the checkbox next to it.

## Use

1. Start a new world or load an existing one in Minecraft.
2. Play the game as usual. The chess pieces in the game will now feature custom faces with brown hair and brown eyes.
